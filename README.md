Week 1ShopSmart Retail Data Analysis
This project prepared for ShopSmart, brings together cleaned and modeled retail data for analysis through an Executive Dashboard and supporting reports. It covers 10 source datasets containing 100,616 operational records, including 50,000 orders, 5,000 customers, 500 products, and 25 stores.
Data preparation included checks for exact duplicate rows and blank values; neither was found. Dates were standardized, currency values were stored as numbers and formatted appropriately, and all source datasets were converted into Excel Tables. These checks address duplicates, missing values, and formatting, but do not establish that every source value is accurate.
Start with the Executive Dashboard for an overview. For supporting calculations and analysis, use Formula Summary, Lookup functions, Business Questions, Business Report, Charts, and the Pivot sheets. On the dashboard, use the interactive slicers to filter by Year, Month, Region, Store, Category, and Membership Level.
